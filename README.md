# 一枝苓｜個人插畫作品集網站

四個頁面：首頁、作品集、委託資訊、關於我。原生 HTML / CSS / JavaScript，無須建置。

## 如何開啟

1. 將 ZIP 解壓縮，使用 VS Code 選取「檔案 → 開啟資料夾」，選擇 `yizhiling-portfolio`。
2. 直接用瀏覽器開啟 `index.html`，或在 VS Code 使用 Live Server 延伸模組預覽。
3. 頁面中的導覽列可切換四個頁面。支援手機版、作品分類篩選、圖片放大及深淺色模式。

## 重要：作品圖片尚未置入原畫

此版本在 `images/work-01.svg` 至 `work-09.svg` 放了 **9 張明確標示為佔位圖的插畫位置**。這些不是你的原畫。圖片訊息在對話中可見，但檔案原始資料未被提供給網站建置環境，因此未擅自模擬成你的畫作。

**替換方法**：
1. 將正式圖片放進 `images/`，例如 `images/my-art-01.jpg`。
2. 打開 `js/data.js`，修改對應作品的 `image` 欄位，例如 `image:"images/my-art-01.jpg"`。
3. 若要修改作品分類、標題、順序，可以調整 `title`、`category`，或搬動作品項目的順序。首頁選用前 3 件作品；作品集會呈現全部作品。
4. 首頁主視覺、委託卡片及關於我代表圖會自動讀取 `data-work-index` 對應的圖片；若要指定不同作品，修改 HTML 中該屬性的數字即可。
5. `alt` 欄位建議換成作品實際描述，提高無障礙品質。

## 如何切換委託開放狀態

編輯 `js/data.js`：

```js
commissionOpen: true,  // 開放委託
commissionOpen: false, // 暫停接受委託
```

**只留下其中一行**，存檔後重新整理網站。首頁導覽列與委託頁會同步更新。這是靜態網站設定，不是訪客可以操作的開關；你更新檔案後重新上傳到網站主機即可公開更新。

## 修改網站外觀

- `css/style.css` 頂端 `:root`：淺色主題色彩。
- `:root[data-theme="dark"]`：深色主題色彩。
- 各頁 HTML：頁面文字與內容。
- `js/main.js`：分類篩選、燈箱、選單和主題切換等互動。

## 部署（選用）

這是純靜態網站，可部署到 GitHub Pages、Netlify 等靜態網站平台。部署之前請檢查作品圖片著作權與委託狀態。網站中文字體優先使用 Google Fonts；離線時會使用系統備援字體。
